# 人判指标评分细则

用于 `score.py` 覆盖不到的三项。每项 0–3 分，可多人独立评分后取均值。

## 1. 结构匹配度（检索出的案例是否真的同构）

| 分 | 判定 |
| --- | --- |
| 3 | 每个案例都能与情景互换主语而语义不变（去掉时代外壳后是同一个结构） |
| 2 | 多数案例同构，个别只是主题相近 |
| 1 | 只是主题相近（"都是职场问题"这种层级） |
| 0 | 案例与情景无关 |

## 2. 可执行性（行动方案是否落到动作）

| 分 | 判定 |
| --- | --- |
| 3 | 每条都是可执行动作，含检验节点或量化标准 |
| 2 | 有具体动作，但缺少检验方式 |
| 1 | 只有方向性建议（"要加强沟通"这类） |
| 0 | 只有情绪安抚 |

## 3. 风险提醒恰当性

| 分 | 判定 |
| --- | --- |
| 3 | 明确说明样本偏差、不能推概率、时代差异，且不削弱可用性 |
| 2 | 提到局限但较笼统 |
| 1 | 只有一句免责声明 |
| 0 | 把历史结局当作对用户的预测 |

## 使用注意

- 评分前先隐藏输出的来源（哪一臂），避免预期偏差
- 至少两人独立评分；分歧超过 1 分的条目重新讨论
- 评分记录保留原始分项，不只留总分
